I am currently taking apart a robot vacuum and a HP printer and to work on these projects I realised that I would need a logic analyzer to debug serial connections between different components
I researched and found a RPI Pico based firmware which can allow the microcontroller to serve as a multi channel logic analyzer hence decided to make a breakout board based around that.
